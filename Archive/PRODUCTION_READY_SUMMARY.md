## 🔥 Typography System Summary

All text uses **AppTypography** exclusively:

```swift
// Headers (32pt, 28pt, 22pt, 20pt)
AppTypography.largeTitle(.bold)
AppTypography.title1()
AppTypography.title2()
AppTypography.title3()

// Body (17pt, 16pt, 15pt)
AppTypography.headline()
AppTypography.body()
AppTypography.callout()

// Small (14pt, 13pt, 12pt, 11pt)
AppTypography.subhead()
AppTypography.footnote()
AppTypography.caption1()
AppTypography.caption2()

// Special (40pt, 80pt, custom)
AppTypography.display()
AppTypography.displayXL()
AppTypography.font(size:weight:)
```

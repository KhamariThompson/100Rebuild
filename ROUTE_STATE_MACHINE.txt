NODES (Routes)
================================================================================

◯ Splash         - Initial loading screen
◯ Auth           - WelcomeView (SignUp/SignIn)
◯ Loading        - Wait for entitlements (max 4s)
◯ Funnel         - ImprovedFunnelView (onboarding questions)
◯ Paywall        - PaywallView or FoundersOfferView
◯ MainPro        - Main app (requires Pro access)

EDGES (Transitions with Conditions)
================================================================================

┌──────────────────────────────────────────────────────────────────────────┐
│ FROM: Splash                                                             │
└──────────────────────────────────────────────────────────────────────────┘

  Splash → Auth
    [!isAuthenticated]
    ✅ CORRECT: Not signed in → show auth

  Splash → Loading
    [isAuthenticated AND !entitlementsLoaded AND elapsed < 4s]
    ✅ CORRECT: Wait for subscription data

  Splash → (continues to routing logic below)
    [isAuthenticated AND (entitlementsLoaded OR timeout > 4s)]

┌──────────────────────────────────────────────────────────────────────────┐
│ FROM: Auth (after successful signup/signin)                             │
└──────────────────────────────────────────────────────────────────────────┘

  Auth → Funnel
    [isAuthenticated AND isPro=false AND isNewSignup=true AND !hasCompletedFunnel]
    ✅ CORRECT: New post-cutoff user within 10min window → show funnel
    ⚠️ ISSUE: Only works within 10-minute grace period!

  Auth → Paywall
    [isAuthenticated AND isPro=false AND isNewSignup=false AND !hasCompletedFunnel]
    ❌ CRITICAL BUG: New post-cutoff user after 10min → SKIPS FUNNEL
    This violates requirement: "Never SignUp → Paywall"

  Auth → MainPro
    [isAuthenticated AND isPro=true]
    ✅ CORRECT: Grandfathered or paid user → immediate app access

┌──────────────────────────────────────────────────────────────────────────┐
│ FROM: Funnel (after completion)                                         │
└──────────────────────────────────────────────────────────────────────────┘

  Funnel → Paywall
    [completeFunnel() called → sets hasCompletedFunnel=true]
    [isPro=false → routes to .paywall]
    ✅ CORRECT: Funnel complete, not Pro → show paywall
    ⚠️ ISSUE: hasCompletedFunnel stored in UserDefaults (device-local)

┌──────────────────────────────────────────────────────────────────────────┐
│ FROM: Paywall (after purchase or dismissal)                             │
└──────────────────────────────────────────────────────────────────────────┘

  Paywall → MainPro
    [purchase successful → isPro=true]
    ✅ CORRECT: Purchased Pro → grant access

  Paywall → Paywall
    [dismissed → isPro=false]
    ✅ CORRECT: Non-Pro users blocked at paywall

┌──────────────────────────────────────────────────────────────────────────┐
│ SPECIAL CASES                                                            │
└──────────────────────────────────────────────────────────────────────────┘

  (Any) → Auth
    [sign out triggered]
    ✅ CORRECT: Sign out returns to auth

  (Any) → Loading
    [entitlements refresh in progress]
    ✅ CORRECT: Show loading during refresh

  Offline First Run → Paywall
    [isAuthenticated AND accountCreatedAt=nil AND entitlementsLoaded=false]
    ❌ BUG: Offline user sees Paywall (can't purchase OR complete funnel)

GATE SUMMARY
================================================================================

PRIMARY GATES (AppRouter.swift:88-150):

  1. isAuthenticated
     Source: UserSession.isAuthenticated (Firebase Auth state)
     ✅ Reliable: Session-based, handles token refresh

  2. isPro
     Source: SubscriptionStore.isPro (RC Pro OR Grandfather Pro)
     ✅ Reliable: Server-backed (RevenueCat + Firestore)

  3. accountCreatedAt
     Source: Firestore users/{userId}.accountCreatedAt
     ✅ Reliable: Server-backed, backfilled from Auth.metadata

  4. isNewSignup (TIME-BASED)
     Source: now - accountCreatedAt < 10min
     ❌ UNRELIABLE: Fails across sessions/reinstalls/devices

  5. hasCompletedFunnel
     Source: UserDefaults['onboardingCompletedAt'] != nil
     ❌ UNRELIABLE: Device-local, lost on reinstall

  6. completedOnboarding
     Source: Firestore users/{userId}.hasCompletedOnboarding
     ⚠️ UNUSED: Never set by funnel, unclear purpose

FEATURE FLAGS (Constants.swift:134-154):

  7. routingV2Enabled
     Always true in Release
     ✅ Safe: Compile-time controlled

  8. overrideNoFunnel
     Always false in Release
     ✅ Safe: DEBUG-only bypass

CRITICAL ISSUES SUMMARY
================================================================================

❌ ISSUE #1: Time-based isNewSignup gate
   Location: AppRouter.swift:125-129
   Problem: After 10min, post-cutoff users route to Paywall, skipping Funnel
   Impact: Violates "Never SignUp → Paywall" requirement

❌ ISSUE #2: UserDefaults-based hasCompletedFunnel
   Location: UserSessionExtensions.swift:26-28
   Problem: Device-local storage lost on reinstall/device change
   Impact: Users may redo funnel OR get wrong route

⚠️ ISSUE #3: Two overlapping onboarding flags
   Locations: UserSession.swift:55 vs UserSessionExtensions.swift:26
   Problem: hasCompletedOnboarding vs hasCompletedFunnel semantic confusion
   Impact: Routing logic unclear, maintenance burden

⚠️ ISSUE #4: Offline routing broken
   Location: AppRouter.swift:94-106
   Problem: Offline users timeout → route to Paywall (can't proceed)
   Impact: Poor UX, users stuck

RECOMMENDED FIXES (Phase B)
================================================================================

1. REMOVE time-based isNewSignup gate
   → Use hasCompletedFunnel (server-backed) as SSOT

2. MIGRATE hasCompletedFunnel to Firestore
   → Primary: Firestore users/{userId}.funnelCompleted
   → Secondary: UserDefaults (cache only)

3. CONSOLIDATE onboarding flags
   → Keep funnelCompleted (Firestore)
   → Remove hasCompletedOnboarding OR clarify semantic difference

4. IMPROVE offline handling
   → Allow Funnel offline (sync funnelCompleted when online)
   → Block Paywall if offline (can't purchase anyway)

5. ENFORCE routing invariants
   → Post-cutoff users: MUST see Funnel before Paywall
   → Grandfathered users: MAY skip Funnel (free access)
   → Offline users: Allow Funnel (delay Paywall until online)
